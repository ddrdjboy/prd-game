# 暗黑霓虹 UI 重设计

**日期：** 2026-09-28  
**范围：** 全部屏幕（Home / CareerPick / Play / Settlement）与组件（TopBar / Board / SlotMachine / FinancePanel / Portrait / 弹层）  
**目标：** 把原型换成现代「暗黑霓虹」视觉：深色底、霓虹渐变发光、玻璃拟态面板；**手机竖屏优先**

## 原则

1. **换皮 + 组件升级**：只改外观与展示动效；布局结构、交互流程、按钮文案、DOM 层级不变
2. **`game/` 零改动**；TSX 仅允许补 class 与纯展示动画（见「TSX 允许改动」）
3. **设计变量单一来源**：所有色值 / 发光 / 圆角 / 动效时长只在 `tokens.css` 定义，组件 CSS 只引用变量
4. **克制发光**：只有可交互或激活态发光；静止元素不发光
5. **竖屏高度预算不变**：沿用 [Mobile Web 适配](./2026-09-25-mobile-web适配设计.md) 的各区块高度
6. **不加依赖**：不引入 Tailwind / UI 库 / 网络字体

## 视觉语言

### 背景

- 基底：`#07060f` → `#120d2a` 纵向渐变
- 光晕：左上淡品红径向光、右下淡青色径向光（静态）
- 纹理：极淡静态网格线（`background-image` 线性渐变实现，无动画）

### 色板（`tokens.css`）

| 变量 | 值 | 用途 |
|------|----|------|
| `--c-bg-0` / `--c-bg-1` | `#07060f` / `#120d2a` | 页面底 |
| `--c-surface` | `rgba(24, 18, 48, 0.72)` | 玻璃面板底 |
| `--c-surface-solid` | `#141030` | 棋盘格等不透明底 |
| `--c-line` | `rgba(180, 160, 255, 0.16)` | 常规描边 |
| `--c-ink` | `#f1eeff` | 正文 |
| `--c-muted` | `#9a93b8` | 次要文字 |
| `--c-primary` / `--c-primary-2` | `#ff2bd6` / `#8b5cf6` | 主操作渐变（品红→紫） |
| `--c-info` | `#22e4ff` | 信息、次要操作 |
| `--c-gold` | `#ffd23f` | 金钱、777、大奖 |
| `--c-pos` | `#3dffa2` | 收益、正面数值 |
| `--c-neg` | `#ff4d6d` | 亏损、危险、破产 |

### 座位色

与现行语义一致（0 = 玩家金），棋子 / 店铺描边 / 财报三处一致：

| 座位 | 变量 | 值 |
|------|------|----|
| 0（玩家） | `--seat-0` | `var(--c-gold)` |
| 1 | `--seat-1` | `var(--c-info)` |
| 2 | `--seat-2` | `var(--c-pos)` |
| 3 | `--seat-3` | `var(--c-primary)` |

### 格子类型描边色

| 类型 class | 描边 |
|------------|------|
| `kind-payday` / `kind-invest` | 金 |
| `kind-shop` / `kind-manage` / `kind-relation` | 绿 |
| `kind-office` | 青 |
| `kind-casino` | 红 |
| `kind-vacant` | `--c-line` 加亮 |

### 面板材质

- 玻璃面板：`--c-surface` + 1px 渐变描边 + 圆角 12px（小）/ 16px（大）
- `backdrop-filter: blur()` **仅用于顶栏与弹窗**；棋盘格、列表行一律实色

### 发光

- 三档：`--glow-sm` / `--glow-md` / `--glow-lg`，均为 `box-shadow` 组合，接收颜色变量（如 `--glow-color`）
- 使用场景：当前格、按钮 hover/active、拉霸转动、组合奖 / 777、聚焦输入框
- `@media (prefers-reduced-motion: reduce)`：关闭闪烁、脉冲、跑马灯、数字滚动（直接显示终值）

### 字体

- 移除未加载的 `"DM Serif Display"`；统一 `system-ui, "PingFang SC", "Noto Sans SC", sans-serif`
- 标题：粗体（700–800）+ 可选渐变文字（`background-clip: text`）
- 所有数字：`font-variant-numeric: tabular-nums`

### 按钮

| 变体 | 外观 |
|------|------|
| `button.primary` | 胶囊形品红→紫渐变 + `--glow-sm`；`:active` 缩小至 0.97 |
| `button`（默认） / `button.ghost` | 透明底 + 青色细描边；hover 描边发光 |
| `button.danger`（新增，用于「结束」确认、卖店等不可逆操作） | 红色描边 |
| `:disabled` | 降低不透明度、去发光 |
| `:focus-visible` | 青色外光圈 |

### 动效时长

`--dur-fast: 120ms`、`--dur-base: 220ms`、`--dur-slow: 420ms`；缓动 `--ease-out: cubic-bezier(0.2, 0.8, 0.2, 1)`。

## 文件结构

| 文件 | 改动 |
|------|------|
| `web/src/styles/tokens.css` | **新建**：全部设计变量 |
| `web/src/styles/global.css` | 引入 tokens；重写背景、按钮、面板、弹窗、输入框、减少动效；旧变量名（`--accent` `--accent2` `--panel` `--line` `--ink` `--muted` `--danger` `--bg0` `--bg1` `--font-display` `--font-body`）先保留为指向新变量的别名，全部组件迁移后删除 |
| `web/src/ui/components/*.css`、`web/src/ui/screens/*.css` | 逐个改为只引用变量，去掉写死色值 |
| `web/src/index.css`、`web/src/App.css`、`web/src/assets/{hero.png,react.svg,vite.svg}` | 删除（Vite 模板残留，未被引用；删除前 grep 确认） |

### TSX 允许改动

- 补 class：财务数值涨跌闪烁（如 `.flash-pos` / `.flash-neg`）、拉霸 777 跑马灯容器、危险按钮 `.danger`
- 结算页数字滚动：纯展示 hook（`requestAnimationFrame` 插值，读已算好的终值；减少动效时直接显示终值）
- 不改按钮文案、不改 DOM 层级、不改 `data-*` / `aria-*`（e2e 依赖）
- `web/src/game/` 不改

## 验证

1. `cd web && npm test && npm run build` 通过
2. `cd web && npm run test:e2e` 通过
3. Playwright 截图人工检查，尺寸 390×844 与 1280×800：首页、选职业、对局页（空闲 / 拉霸中）、事件弹窗、结算页；确认竖屏各区块未超出高度预算、无横向滚动

## 风险

- `PlayScreen.css`（约 480 行）中定位、层级、溢出等功能性样式与装饰样式混在一起：迁移时只替换色值 / 阴影 / 圆角 / 字体，不动 `position` `z-index` `overflow` `inset` `height` 等布局属性
- 低端安卓发光掉帧：发光仅激活态；棋盘格与列表行禁用 `backdrop-filter`

## 非目标

- 不改玩法逻辑、布局结构或交互流程
- 不做亮色主题 / 主题切换
- 不引入网络字体、图标库或 CSS 框架
- 不做背景动画（光晕、网格均静态）
