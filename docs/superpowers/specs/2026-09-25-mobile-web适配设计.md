# Mobile Web 竖屏布局设计（棋盘优先）

**日期：** 2026-09-25  
**范围：** Play 对局页（竖屏 ≤640px）  
**目标：** 地图尽量大、操作条尽量薄；桌面布局不变

## 原则

1. **棋盘是主视觉**：竖屏下优先占满可用宽度做成正方形
2. **Chrome 极薄**：顶栏 / 财务 / 操作 / 日志合计约 ≤ 11rem
3. **操作是工具条**：主按钮一行矮条 + 四列次要按钮，不再 2×2 大砖块
4. **桌面（>640px）行为与视觉不变**

## 竖屏结构（自上而下）

| 区块 | 高度预算 | 说明 |
|------|----------|------|
| 顶栏 | ~2.2rem | 隐藏标题，只留「岁·季」+ 细进度条 + 小按钮 |
| 棋盘 | 剩余空间 | `min(屏宽, 100dvh-10.75rem)`，圈切换条 26px |
| 财务条 | ~1.5rem | 单行摘要，可展开 |
| 操作条 | ~4.2rem | 状态行 + 拉霸 34px + 四列 30px |
| 日志条 | ~1.3rem | 标题 + 最近一句 |

## 操作区

- 主操作：`777 拉霸` 全宽、高度 ~34px
- 次要：`约会 / 店铺 / 好友 / 结束` 四等分一排、高度 ~30px
- AP / 当前回合收进操作条顶一行，不再单独大段说明

## 棋盘中心

- 拉霸机缩小（约 58% 宽），格子字号略放大，中心洞 inset 加大以露出更多格

## 非目标

- 不改游戏逻辑
- 不做 PWA / 横屏专属
- Home / Career / Settlement 仅沿用既有触控尺寸
