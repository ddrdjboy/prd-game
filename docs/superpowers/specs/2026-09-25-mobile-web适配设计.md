# Mobile Web 竖屏布局设计（棋盘优先）

**日期：** 2026-09-25（2026-09-29 改为长方形环）  
**范围：** Play 对局页（竖屏 ≤640px 为主，桌面共用同一结构）  
**目标：** 地图尽量大、占满屏高；桌面观感基本不变

## 原则

1. **棋盘是主视觉**：竖屏下正方形环会被屏宽卡死、浪费纵向空间，所以环按容器比例变形为竖长方形
2. **格数与格序不变**：周长恒为 36 格，只改显示几何；落点、发薪、移动逻辑不受影响
3. **操作收进环中心**：圈切换、拉霸机、日志一行、次按钮、主按钮都放在环中心空洞，环外只剩顶栏
4. **桌面（宽屏）仍为 10×10**

## 环形状选择

- 候选形状满足 `cols + rows = 2 × SPACES_PER_SIDE`（当前 20）：`10×10、9×11、8×12、7×13、6×14`，中心至少留 4 列
- `board.ts` 的 `fitRing(宽, 高)` 选单格宽高比最接近 1 的一组，单格长宽比上限 1.3，超出时缩小该轴
- `ringCoord(index, cols, rows)` 顺时针映射外圈坐标，index 0 在左上角；`squareCoord` 是 `cols = rows` 的特例
- `Board.tsx` 用 `ResizeObserver` 量 `.board-fill`，把尺寸与 `--ring-cols / --ring-rows / --cell-w` 写到 `.board-stack`
- 参考结果：390×844 → 7×13（单格约 48×50px）；375×667 → 8×12；1280×800 → 10×10

## 竖屏结构（自上而下）

| 区块 | 高度 | 说明 |
|------|------|------|
| 顶栏 | 约 6rem | 岁·季、财务 chip、双进度条、三态推进（全自动 / 半自动 / 手动）、速度 |
| 棋盘环 | 剩余全部 | 占视口高度 ≥ 70%（`e2e/visual.spec.ts` 断言） |

## 环中心（自上而下）

- 圈切换胶囊（行走中锁定时附一行提示）
- 拉霸机：居中，竖屏约占中心宽 92%（上限 230px）
- 本季日志：标题 + 最近一句，点开看全部
- 次按钮：`约会 / 店铺 / 好友` 三等分，高度约 30px
- 主按钮：`777 拉霸` / `结束回合` / `推进 AI`，全宽约 40px

## 格子

- 字号随单格宽度：`clamp(0.55rem, cell-w × 0.2, 0.82rem)`；棋子 7–11px 随格宽缩放

## 非目标

- 不改游戏逻辑
- 不做 PWA / 横屏专属
- Home / Career / Settlement 仅沿用既有触控尺寸
