# 财富自由后的自由生活

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-04 |
| 状态 | 已定稿（实现基线） |
| 替代 | 投资人圈 / 外圈棋盘 / 晋级启动金 |

## 目标

被动收入覆盖总支出后，打工人圈结束，进入第一人称「自由生活」：地点图 + 场景立绘对白 + 会所回合战。终局仍到 45 岁；主结算净资产，副结算见过的角色数。

## 触发

人类玩家在回合结束（或等价门槛点）满足 `isFinanciallyFree`（被动收入 ≥ 总支出且支出 > 0）时，进入自由生活，不再弹出「晋级投资人圈」。

- 删除：`Track = 'investor'` 的玩法路径、外圈棋盘、`INVESTOR_START_BONUS`、`PROMOTE_TO_INVESTOR` / `SKIP_PROMOTE`。
- 旧存档若 `track === 'investor'`：迁移为 `lifeMode: 'free'`，保留财务与关系。
- 进入后若选项使支出再次超过被动收入：留在自由生活，不退回棋盘；结算仍报净资产，并标明自由是否仍成立。

## 时钟与行动点

| 打工人阶段 | 自由生活 |
|---|---|
| 一年 4 季 | 一年 12 月（`monthIndex` 0–11） |
| 每季 1 AP | 每月 4 AP |
| 四季完年龄 +1 | 12 月完年龄 +1 |
| 财务 / 关系衰减按季 | 按月；金额与衰减为原季值的 **1/3** |

花 1 AP 去一个地点。4 点用完 → 月结（现金流入账、关系衰减）→ 下月。打到 `endAge` 后结算。

AI 席位：不在地点图上花 AP；每月结算时其店铺/投资仍按月滚（1/3 季值）。结算页可对比。

## 地点

**28 处固定地点**分属四区（每区 7 个）。先看 2×2 缩略总览，点进某一区再显示该区大图与针脚；SW「梧桐里」另加**好友的家**动态针脚。不走格子。

| 区 | 地点 |
|---|---|
| NW 水岸 | 江边、咖啡馆、码头、独立书店、茶馆、瑜伽馆、花店 |
| NE 文创 | 画廊、小博物馆、创作工作室、独立影院、手作摊、城市书房、天台酒廊 |
| SW 生活 | 我家、市集、健身房、社区诊所、生鲜超市、街心公园、社区夜校 |
| SE 城东 | 旧事务所、会所、私人银行、酒店大堂、西餐厅、电玩城、水疗馆 |

- **我家** = 玩家住宅；**好友的家** = 已结识且非仇恨的名册角色动态针脚（`FREE_VISIT_FRIEND`），叠在梧桐里公寓簇。
- **会所**仍是唯一 PK；其余地点按 vibe（home/chat/date/creative/market/rest/office/friendHome）抽场景池。
- 场景底图按 vibe 复用现有插画，不必每点一张新图。

### 场景效果

选项效果限于：现金、被动收入或一次性资产、好感、任务旗标。第一次与角色对白即计入「收下」（进关系名册）。

### 任务旗标

跨月旗标，最多少量并行。带旗标的地点优先出对应场；完成后改钱/好感并清除。

## 会所 PK

花 1 AP。自动推进**跳过**会所。

### 组队

- 从已见过且非仇恨的朋友中选 1–6 人。
- 战斗三项（仅本场）：现金=血量，被动收入=攻击，资产=出手顺位。
- 由技能底数 × 好感阶乘：冷淡 0.6 / 中立 1 / 友善 1.3 / 亲近 1.6 / 亲密 2。
  - 手艺、创作 → 偏血量
  - 服务、销售 → 偏攻击
  - 经营 → 偏资产（先手）
  - 无技能：三项小底数

### 电脑队

最多 6 人；优先玩家未见过的名册角色，三项按友善算；不足用不可挖走的班底补满。不随玩家财富抬数值。

### 回合

1. 两边存活者按资产降序出手；同资产玩家优先，再按组队栏左→右。
2. 目标：对方存活中血量最低者。
3. 伤害 = 攻击 + `rng * 攻击`（0…攻击）；（20% 暴击）×2。
4. 血量 ≤ 0 → 本场倒下，不再出手。
5. 一方全灭即负；打满 30 回合比存活血量合计。

战斗中扣的血不改玩家真账。

### 胜负结算

| | 胜方 | 败方 |
|---|---|---|
| 真账 | 现金 +0.2 / 月被动 +0.05 / 一次性资产 +0.3 | 同额扣除，下限 0，不造负债 |
| 挖人 | 从败方出战名单带走 1 人 | 失去 1 人 |

- 玩家赢：自选一名对方出战且自己未见过的角色；好感中立，计入收下。无可挖对象 → 额外小笔现金。
- 玩家输：带走战斗结束时血量最低（先倒下优先）的出战朋友；离开名册，可在常驻地再遇。

## 结算（45 岁）

- **主**：净资产（现金 + 店铺 + 投资 − 负债）。
- **副**：见过的角色数（名册人数）。
- 立绘解锁进图鉴，不另计分。
- 是否仍财富自由：用现行 `isFinanciallyFree` 展示。

## 界面

自由后：隐藏双圈棋盘与拉霸。主画面先为 **四区缩略总览**（`free-life-map-{nw,ne,sw,se}.jpg` 拼 2×2），点选区域进入该区大图与 7 处针脚（生活区另见好友家）；可返回总览。顶栏叠在地图上（AP / 结束本月 / 返回）。进地点 → 场景卡；会所 → 组队 → 战斗 → 挖人。区内坐标见 `web/src/ui/freeLifeMapLayout.ts`。
