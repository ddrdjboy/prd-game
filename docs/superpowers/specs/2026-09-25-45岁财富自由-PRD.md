## 1. 背景与机会

### 1.1 灵感来源

| 来源 | 可借鉴核心 |
|---|---|
| DOS《华丽人生2》（1994，Fairy Tale / 天堂鸟） | 掷骰绕圈、关系人经营店铺、关系维护与争夺、多人对战张力 |
| 桌游 Cashflow（富爸爸） | 财务报表、工资/支出/被动收入、打工人圈→投资人圈、资产与负债思维 |

### 1.2 问题陈述

经典财商桌游偏长、偏教学；华丽人生类玩法有趣但含不当内容且难在现代网页传播。需要一款：

- **15–25 分钟**可完成的网页快局
- **全年龄**关系经营（人脉 + 恋爱，非成人）
- 用「45 岁能不能财富自由」做清晰娱乐目标

### 1.3 产品一句话

从 18 岁选职业入场，用四季推进走到 45 岁；在打工人圈经营人脉/恋爱与小店抬被动收入，达标后可晋级投资人圈；终局以财富自由是否达成 + 总资产 / 人脉 / 恋人关系三维评分。

## 2. 目标与非目标

### 2.1 目标（MVP）

1. 单页网页可完整体验一局（2–4 席，1 人 + AI 补位）
2. 开局职业卡 **3 选 1**，18 岁春开局，45 岁冬结算
3. 双圈身份：打工人 / 投资人；晋级条件为被动收入 > 总支出
4. 人脉与恋爱均为**核心玩法**（非扩展包），驱动开店与被动收入
5. 普通季支持一键自动；关键决策打断手操，目标中位时长 15–25 分钟
6. 结算页给出财富自由判定 + 三维雷达与人生评语

### 2.2 非目标（首发不做）

- 在线实时多人 / 排行榜账号体系（可预留数据模型）
- 成人内容、露骨描写
- 真实税率/通胀仿真、开放世界剧情
- 实体桌游组件量产
- 完整 Cashflow 全卡牌复刻或华丽人生角色复刻

## 3. 用户与场景

### 3.1 目标用户

- 喜欢大富翁 / 人生局、想轻量玩「搞钱」叙事的 18–35 玩家
- 知道一点财商概念、但不想上课的休闲玩家
- 单人碎片时间：通勤后、午休，开一局网页即走

### 3.2 核心场景

1. **首局**：打开页面 → 选人数 → 职业 3 选 1 → 教程 90 秒内结束 → 开始四季循环  
2. **中局**：看财富自由进度条，决定维护关系还是加仓投资；被 AI 挖角时反击或放弃  
3. **晋级**：被动收入首次超过支出，选择进入投资人圈，体感「身份变了」  
4. **收官**：45 岁结算，晒雷达图，一键再来一局换职业

## 5. 核心循环与时间轴

### 5.1 双圈定位

| 圈层 | 身份 | 玩家在做什么 |
|---|---|---|
| 内圈·打工人 | 工资养活自己 | 领薪、控支出、经营人脉/恋爱、开小店、抬被动收入 |
| 外圈·投资人 | 被动收入已覆盖支出后可选晋级 | 更大标的、更高波动；**不结束对局**，继续打到 45 岁 |

**晋级条件（回合开始时判定）**：被动收入 **>** 总支出 → 可选择进入投资人圈。

### 5.2 日历

- 开局：**18 岁 · 春**
- 终局：**45 岁 · 冬** 结束后统一结算
- **一季 = 一整轮**（所有玩家各行动 1 次）
- 顺序：春 → 夏 → 秋 → 冬；冬结束年龄 **+1**
- 总长度：27 年 × 4 季 = **108 季**
- **四季事件池相同**，事件随机抽取（不做春夏秋冬差异权重）

### 5.3 单回合流程

> **v1.1：** 以下为 v1.0 原文。现行流程见 §0.2（拉霸走格 → 拉霸事件选项 → 落点互动 → 约会 AP）。

1. ~~掷 1 骰，棋子在当前圈移动~~ → 拉下 777，第 1 位决定步数  
2. ~~触发落格事件（从对应类型牌堆随机 1 张）~~ → 第 2/3 位定事件大类与牌；玩家选选项  
3. ~~可选消耗本季行动点：维护人脉 / 约会 / 经营店铺 三选一~~ → 落点互动后，可选耗 1 AP「约会·交友」  
4. 刷新财务报表  
5. 全员行动完毕 → 进入下一季；若刚结束冬 → 年龄 +1  

### 5.4 快局策略（方案 A）

- 默认提供「一键自动本季 / 连续自动」
- **普通季**自动代操；下列 **关键决策** 打断手操：
  - 破产边缘（现金不足以支付强制支出）
  - 可晋级投资人圈
  - 结婚 / 分手确认
  - 大额投资或借贷（超过阈值，如 > 当前现金 50%）
  - 针对玩家的挖角事件
- 灵敏度设置：少打断 / 标准 / 多打断
- AI 回合默认极速，可跳过动画

### 5.5 终局评价（无「抢梦想主胜」）

| 维度 | 说明 |
|---|---|
| 财富自由判定 | 终局是否满足 被动收入 > 总支出（是/否，标题级结果） |
| 总资产 | 现金 + 资产市值 − 负债 = 净资产 |
| 人脉 | 数量 × 平均信任 × 事业合伙人加成 |
| 恋人关系 | 现存质量 − 重大破裂惩罚 + 长期婚姻加成 |

输出：综合评级（S/A/B/C）+ 三维雷达 + 短评语；同桌对比（含 AI）强调娱乐复盘。

## 6. 关系系统（人脉 + 恋爱）

### 6.1 设计原则

职场人脉与恋人共用「关系资产」框架，均为核心玩法；服务开店、被动收入与终局评分。

### 6.2 两类关系人

| 类型 | 来源示例 | 主要产出 | 维护 |
|---|---|---|---|
| 人脉 | 同事、客户、合伙人、导师 | 生意机会、开店挂名、被动收入修正、信息差 | 饭局/送礼/时间 → 支出或占用行动点 |
| 恋人 | 关系事件结识 | 支出波动缓冲、共同资产/家庭开支、终局恋人分 | 约会/陪伴；疏于维护降温或分手 |

### 6.3 共同数值

- **信任/感情**：0–100，影响产出倍率与流失风险  
- **状态线**  
  - 人脉：结识 → 稳定 → 事业合伙人（可锁定）  
  - 恋人：结识 → 交往 → 订婚/结婚（可锁定）  
- **绑定资产**：店铺/项目可挂经营者；关系破裂 → 收入下降或流失风险  

### 6.4 与经营咬合

- 开店需至少绑定 **1 名**人脉或恋人作为经营者  
- 被动收入 × 关系质量修正  
- 打工人圈：关系是抬被动收入的主加速器  
- 投资人圈：人脉解锁更大标的；婚姻可能提高固定支出，同时提高共同资产上限  

### 6.5 挖角与争夺

- AI（及未来玩家）可对未锁定关系发起挖角：耗资源 + 判定  
- 成功：关系转移或原主人信任大减  
- 结婚 / 事业合伙人：**锁定**，大幅降低被挖概率

## 7. 职业卡 · 财务报表 · 店铺与投资

### 7.1 开局：职业卡 3 选 1

系统从职业池随机抽 **3 张**，玩家选 **1 张**（18 岁春入职）。AI 按权重自选。

每张职业卡字段：

| 字段 | 说明 |
|---|---|
| 职业名 | 如程序员、销售、护士、公务员、设计师等 |
| 工资收入 | 发薪/过季结算入账 |
| 固定支出 | 生活基线 |
| 起始现金 | 开局存款 |
| 开局被动收入 | 多为 0 |
| 特质（1 条） | 例：人脉事件+10% / 恋爱好感更快 / 投资折扣 / 支出抗性 |

平衡原则：特质可有性格差，**起始数值避免碾压**。

### 7.2 财务报表（常驻）

```
工资收入
+ 被动收入（店铺 / 投资 / 关系分红）
= 总收入
− 总支出（固定 + 关系维护 + 家庭/婚姻 + 事件）
= 季度现金流

资产（现金、店铺、投资标的）
− 负债
= 净资产

财富自由进度 = 被动收入 / 总支出
（≥ 100% 且被动收入 > 总支出 → 可晋级投资人圈）
```

### 7.3 店铺

- 等级：摊位 → 小店 → 品牌店（投入↑，被动收入↑）  
- 必须绑定经营者（人脉或恋人）  
- 关系质量修正收入；破裂/挖角可停业或易主  
- 娱乐向回本节奏：大约 **2–4 季** 倾向回本（可调参）  

### 7.4 投资标的（精简 Cashflow）

| 类型 | 出现圈 | 说明 |
|---|---|---|
| 小机会 | 两圈皆可，打工人为主 | 低门槛、低现金流 |
| 大机会 | 投资人圈权重更高 | 房产份额、公司股权等 |
| 市场 | 两圈 | 涨跌、出手窗口 |
| 借贷 | 两圈（有上限） | 利息计入支出 |

## 8. 棋盘与事件池

### 8.1 棋盘规格（MVP）

> **v1.1：** 格子是**落点互动**，不再用格子类型抽事件牌。事件由拉霸决定（见 §0）。

| 圈 | 格数 | 典型格子（落点） |
|---|---|---|
| 打工人 | 36（每边 10 格含角） | 发薪、空地、商店、私人事务所、经营区、公园、赌场 |
| 投资人 | 36 | 另含投资所；公园/经营等仍在 |

棋子晋级后移至外圈。实现见 `web/src/game/board.ts`。

### 8.2 事件池

四季共用同一事件池。抽取由拉霸第 2/3 位决定大类与索引；**每条事件须带 choices**（见事件选择子规格）。

| 类型 | 示例 |
|---|---|
| 机会 | 小投资、开店意向、兼职 |
| 市场 | 资产涨跌、出手窗口 |
| 消费 | 突发开支、冲动消费 |
| 关系 | 结识、维护、挖角、冷战 |
| 职业 | 加薪、裁员风险、跳槽 |
| 经营 | 店铺旺淡季、追加投入 |
| 休息 / 现金流日 | 休息池；投资人圈 rest 可映射 cashflowDay |

文案：娱乐向短句，避免说教长文。

## 15. 风险与对策

| 风险 | 对策 |
|---|---|
| 108 季过长 | 强依赖自动季 + 事件合并提示 |

## 17. 设计决策摘要（已拍板）

1. 融合华丽人生2 关系开店 + Cashflow 双圈财报，**娱乐优先**  
2. 人脉 + 恋爱都是核心，**不是扩展包**；全年龄  
3. 网页版先行；**单人 + AI**  
4. **无主胜抢梦想**；18→45，四季一轮，事件同池随机  
5. 开局 **职业卡 3 选 1**  
6. 终局：财富自由判定 + 总资产 / 人脉 / 恋人  
7. 普通季 **一键自动**，关键决策打断，目标 15–25 分钟  
8. 产品名定位：**《45岁财富自由》**  
9. **v1.1：** 移动与事件由 **777 拉霸** 驱动；地图格为落点互动；细节见子规格
