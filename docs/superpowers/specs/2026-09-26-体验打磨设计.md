## 1. 早期第一桶金

- `age < 22`：发薪（`applyPayday`）额外 `EARLY_PAY_BONUS = 0.12`  
- `age < 22`：拉霸抽到 `doodad` 时，若事件 accept 成本 ≥ 0.25，有 50% 改抽同池更便宜的牌（或直接映射到轻量 doodad）——实现简化：抽牌后若 age<22 且 choiceCashCost(accept)>0.3，换成 `dd3`（外卖，decline 免费）这类轻事件  

更简：**仅发薪红利**，避免改抽牌复杂度。

## 2. 维护免衰减 + 预警

- `Relation` 增加可选字段不需要持久复杂：在 `PlayerState` 上挂 `maintainedRelationIds: string[]`，每回合开始清空，约会/公园聊天/事务所升温写入  
- `decayPlayerRelations(player, skipIds)`：skipIds 内本回合不衰减  
- 好友面板：`score - decayPerTurn ≤ BREAK` 时显示「下回合可能破裂」

## 3. 晋级爽感
