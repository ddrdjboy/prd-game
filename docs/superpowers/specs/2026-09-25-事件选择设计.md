# 全类事件选择设计规格

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-25 |
| 状态 | 已定稿（实现基线） |
| 相关 | 拉霸第 2 位定大类、第 3 位抽牌；落点互动不变 |

## 1. 统一选择模型

每条事件必须有 `choices`（2～3 项）：

| choiceId | 标签习惯 | 规则 |
|---|---|---|
| `accept` | 接受 / 跟进 / 买单 / 推进 | 主效果 |
| `decline` | 拒绝 / 观望 / 忍住 / 冷处理 | 无效果或轻副作用 |
| `raise` | 加码 / 加码投入 / 升级消费 / 谈判 | 可选；更高成本与回报；现金不足禁用 |

强制应对类（挖角打到自己）：`defend`（挽留花钱）/ `yield`（放人），映射实现仍用 `accept`/`decline` 标签文案区分。

组合奖（777、对子等）在玩家选选项**之前**已自动入账，与选项无关。

## 2. 数值带（万）

- 小：现金 ±0.1～0.4；关系 ±3～8
- 中：成本 0.8～2.0；被动收入 +0.08～0.25
- 大 / 加码：成本 2.0～4.0+；回报约为 accept 的 1.3～1.6 倍
- decline：通常 0；偶发关系 -2 或错过感（日志即可）

## 3. 各大类规格

### 3.1 机会 opportunity

- **主题**：开店、投资、接单、借贷扩盘
- **选项**：接受 / 拒绝 / 加码投入（多数投资与开店带 raise）
- **示例**：路边摊、兼职、定投、电瓶车份额、咖啡馆、技能变现、信用贷、便利店、公寓、股权

### 3.2 市场 market

- **主题**：涨跌、出手、接盘
- **选项**：跟进（出售/加仓）/ 观望；风口类可加码追涨
- **示例**：上扬、回调、出手窗口、派息、汇率、风口、急售份额、平静周

### 3.3 消费 doodad

- **主题**：冲动与必要开支
- **选项**：买单 / 忍住；部分可「升级消费」（更贵但带关系或心情收益）
- **示例**：手机、婚礼、外卖、健身、牙医、旅行、订阅、红包（红包：收下/转赠）

### 3.4 关系 relation

- **主题**：结识、升温、摩擦、挖角、求婚
- **选项**：推进 / 冷处理 / 加码送礼；挖角：挽留 / 放人；求婚：答应 / 暂缓 / 盛大婚礼
- **示例**：同事、饭局、偶遇、相亲、深谈、冷战、挖角、求婚、导师、周年

### 3.5 经营 business

- **主题**：旺淡季、装修、口碑、联名
- **选项**：追加投入 / 维持（轻收益或无操作）/ 收缩（止损少亏）
- **示例**：旺季、淡季、装修、口碑、员工、供应链、卫生、联名

### 3.6 职场 career

- **主题**：加薪、裁员、跳槽、奖金
- **选项**：接受条件 / 拒绝或躺平 / 谈判加码（加班换更高薪）
- **示例**：加薪、裁员、跳槽、奖金、培训、无薪任务、聚餐、平稳

### 3.7 休息 rest（含原叙事牌）

- **主题**：恢复、轻收益、氛围
- **选项**：享受休息 / 顺便办点事（轻收益）；少数可「认真规划」小收益
- **叙事**：并入休息抽取池，避免死牌

### 3.8 现金流 cashflowDay（投资人圈）

- **主题**：落袋 vs 再投资
- **选项**：落袋为安 / 再投资（及加码再投资）
- **示例**：现金流日、分红、再投资冲动、收息、杠杆、盘点、合伙人、安心日

## 4. AI 选策

| 风格 | 偏好 |
|---|---|
| steady | accept；缺钱或大额偏 decline；少 raise |
| aggressive | accept；有钱则 raise |
| social | 关系类 accept/raise；其余同 steady |

## 5. 实现备注

- `GameEvent.choices` 取代顶层 `effects`
- 动作：`RESOLVE_EVENT_CHOICE { choiceId }`
- 兼容：旧 `RESOLVE_EVENT` 可视为选 `accept`（实现阶段直接替换）
