# 地图格子详情设计

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-28 |
| 状态 | 实现基线 |
| 相关 | `Board.tsx`、`PlayScreen.tsx`、`board.ts`、`location.ts` |

## 目标

玩家可在棋盘上点击任意格子，以只读弹框查看该格的类型说明与当前实况，降低「格子是干什么的」认知成本。不改变任何玩法结算。

## 非目标

- 不从详情弹框发起买店、事务所、赌场等落点操作
- 不新增 `GameAction` / 不写入 `GameState` / 不影响存档
- 不替代落点互动弹层（`pendingLocation`）

## 交互

1. 仅当前可见轨道（打工人圈 / 投资人圈 Tab）上的格子可点。
2. **仅空闲时可点**：与 `PlayScreen` 现有 `busy || browseOpen` 一致——存在待处理事件、决策、落点、约会、走格/拉霸动画、事件回味，或已打开好友/商店/日志/财报浏览时，格子点击无效（可不挂 handler 或挂了也忽略）。
3. 点击格子 → 打开只读详情弹框；再次点击另一格 → 切换为该格详情（若允许在详情打开时点棋盘；MVP：**打开详情时算 browse，禁用其它格子点击**，避免叠层）。
4. 关闭：主按钮「关闭」；点击遮罩关闭。关闭后不 `dispatch`。
5. 与落点弹层互斥：有 `pendingLocation` 时本功能不可用（已含在 busy 内）。

## 弹框版式（单栏紧凑）

复用 `PlayScreen` 现有 `.modal` / `.modal-card` 壳。

| 区块 | 内容 |
|---|---|
| 标题 | `{SPACE_LABELS[kind]} · {圈别中文} #{index}` |
| 副文 | 固定文案「仅查看」 |
| 说明 | 按 `SpaceKind` 的图鉴文案（含关键数值提示，数值取自 `location.ts` 等常量，避免魔法数漂移） |
| 实况 | 见下节 |
| 操作 | 仅「关闭」 |

## 图鉴说明（按 SpaceKind）

文案实现放在 `web/src/game/spaceInfo.ts`，与 UI 解耦；下列为内容要点（中文可微调，语义不变）：

| kind | 说明要点 |
|---|---|
| `payday` | 经过或停在此格时结算工资与固定支出；本格无额外落点菜单 |
| `vacant` | 可开店；造价约 `VACANT_COST`；无合适关系人时另付 `VACANT_HIRE_EXTRA`；已有店则为归属空地，他人踩到可探店 |
| `shop` | 商店：购买消耗品/礼物等（见 `SHOP_ITEMS`） |
| `office` | 私人事务所：推荐好友、调好感、挖角 |
| `manage` | 经营区：管理己方店铺编制/升级等 |
| `park` | 公园：休息回血（`PARK_REST_CASH`）或与关系人聊天（`PARK_CHAT_BOOST`） |
| `invest` | 投资所：买卖理财/标的（投资人圈为主） |
| `casino` | 赌场：小游戏下注娱乐 |

## 当前实况

由纯函数根据 `GameState` + `(track, index)` 拼装字符串列表：

| 信息 | 规则 |
|---|---|
| 站位 | 该 `track`+`position` 上的全部玩家（含 AI）。人类玩家显示「你」，其余用 `player.name`；多人顿号连接，前缀「站在此格：」。无人则「站在此格：无人」。不标注「行动中」（行动高亮仍只在棋盘 token） |
| 店铺（仅 `vacant`） | 若 `findShopAt` 有店：店名（或展示名）+ 老板名；否则「尚未开店」 |
| 其它 kind | MVP 不强制展示额外动态字段（避免与落点菜单重复维护） |

## 架构

```
Board.onSpaceClick(track, space)
  → PlayScreen 若 !busy && !browseOpen → setSpaceDetail({ track, index, kind })
  → 渲染 SpaceDetailModal（或内联 modal）
  → 文案/实况来自 spaceInfo.buildSpaceDetail(state, track, index)
```

| 文件 | 职责 |
|---|---|
| `web/src/game/spaceInfo.ts` | `SPACE_KIND_INFO`、`buildSpaceDetail(...)` |
| `web/tests/spaceInfo.test.ts` | 说明存在性、空地有/无店、站位名单 |
| `web/src/ui/components/Board.tsx` | 格子 `button` 或可点击 div + `onSpaceClick`；禁用时无点击/无 pointer |
| `web/src/ui/components/Board.css` | 可点态 `cursor` / focus；禁用态不变 |
| `web/src/ui/screens/PlayScreen.tsx` | `spaceDetail` 本地 state；并入 `browseOpen` |

## 验收

- 空闲时点击各 `SpaceKind` 均弹出对应说明
- 空地有店时实况显示店名与老板；无店显示尚未开店
- 有人站在该格时名单正确
- `busy` 或其它浏览弹层打开时点击格子无反应
- 关闭详情后可继续拉霸/回合，状态与现金不变
- `npm test` 中 `spaceInfo` 相关用例通过
