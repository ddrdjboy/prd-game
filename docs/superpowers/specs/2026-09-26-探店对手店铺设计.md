# 探店：空地归属格 + 踩到触发会话

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-26 |
| 状态 | 已实现 |
| 触发 | **B**：空地开店后该格变成「某某的店」；非店主踩到才探店 |

## 目标

- 空地开店绑定棋盘格；同格仅一家店
- 非店主踩到进入探店会话：付钱 → 店长聊天 → 选店员加价 → 可选送礼 → 可选挖角+拉霸
- 费用进店主现金；挖角成功则人脉迁至访客并从编制移除

## 棋盘与数据

```ts
Shop {
  // ...既有字段
  boardTrack?: 'worker' | 'investor' | null
  boardIndex?: number | null
}
```

- `LOCATION_BUY_VACANT` 写入当前 `pendingLocation.track` / `spaceIndex`
- 事件开店不写格位 → 不可被踩到探店
- 查找：`findShopAt(players, track, index)`
- 店主踩自己的店：toast「回到自己的店」，清落点、不开会话
- 旧存档：可从 `id` 形如 `lot-{track}-{index}-*` 推断格位

## 会话 `pendingVisitShop`

```text
pay → talkManager → pickStaff → gift? → poach? → done
```

| 阶段 | 行为 |
|------|------|
| pay | 探店费 = clamp(0.4×baseRevenue, 0.08, 0.5)；扣访客、加店主；不足可离开 |
| talkManager | 对店长 +rapport；无店长跳过 |
| pickStaff | 从 staffIds 选一人，小费进店主，+rapport |
| gift | 可选简单礼品档；费用进店主，+rapport |
| poach | 可选；成功率 = poachSuccessChance(对方关系分) + rapport 修正 + 拉霸修正；成功 transferRelation |
| leave | 清 pendingVisitShop + pendingLocation |

### 拉霸修正

本局独立三轮（1–9），不推进棋盘：

- 三同 7：成功率 +0.45（近似必成）
- 任意三同：+0.2
- 两同：+0.1
- 总和 ≥ 24：+0.08
- 总和 ≤ 9：−0.1

挖角另扣小额手续费（0.2 万）并触发挖角冷却。

### AI

pay → 随机店员（有则）→ 跳过送礼 → 低概率挖角或不挖 → 离开。

## 刻意不做

- 事件店不上棋盘
- 不改公共「商店」格
- 不做完整兴趣爱好送礼规格（用简单礼品档）
