# 场景插画与立绘展示设计

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-29 |
| 状态 | 已实现 |
| 范围 | 首页 / 选职业 / 对局弹窗 / 约会 / 结识 / 好友 / 结算的图片化；玩法不变 |

## 目标

原型只有 CSS 面板，20 张角色立绘只在 36–120px 小框里出现。本轮给每个「场景」配图，并把立绘升级为大图，让约会、结识、结算有画面感。

## 原则

- 画风统一：日系动漫插画，夜景，品红 / 青色轮廓光，贴合 [暗黑霓虹 UI](./2026-09-28-暗黑霓虹UI设计.md)
- 图内无文字 / logo；人物着装得体（遵守 `AGENTS.md` 禁忌）
- 场景图是「氛围底」：底部渐隐到面板底色（`--grad-fade`），文字压在实色上
- 竖屏预算：弹窗头图 `--banner-h` 96px，视口高 ≤ 700px 时 `--banner-h-short` 56px
- `game/` 不感知场景图；映射只在 `web/src/ui/art.ts`

## 素材（`web/public/art/*.jpg`，29 张，约 3.6MB）

| 组 | 文件 | 比例 | 对应 |
|---|---|---|---|
| 主视觉 | `home-hero` | 9:16 | 首页整屏底 |
| 对局底 | `play-bg` | 9:16 | 对局页整屏底（`--play-art-opacity`） |
| 结算 | `settle-free` / `settle-grind` | 9:16 | 财富自由达成 / 未达成或破产 |
| 落点 | `space-{payday,vacant,shop,office,manage,park,invest,casino}` | 16:9 | `SpaceKind` |
| 约会 | `venue-{chat,park,cafe,cinema,dinner,hobby,surprise,private}` | 16:9 | `DATE_VENUES[].id` |
| 职业 | `career-{dev,sales,nurse,civil,designer,teacher,chef,lawyer,media}` | 4:3 | `CAREERS[].id` |

事件弹窗不单独出图：`EVENT_ART` 按 `EventKind` 复用（market→投资所、rest→公园、relation→咖啡厅、business→经营区、doodad→商店、opportunity→空地、cashflowDay→发薪、career→销售、narrative→主视觉）。

肖像 `web/public/portraits/g01…g20` 由 PNG（约 1.8MB/张）转为 600 宽 JPEG（约 140KB/张）。

压缩：macOS `sips -s format jpeg -s formatOptions 68 --resampleWidth 800|720`。

## 展示位

| 位置 | 处理 |
|---|---|
| 首页 | `home-hero` 整屏底 + 半透明面板；面板底部「登场角色」横向滚动条（20 位 md 肖像 + 名字 + 身份） |
| 选职业 | 卡片顶部 4:3 插画；竖屏改为左图右文 |
| 对局页 | `play-bg` 低透明度铺底 |
| 事件弹窗 | `SceneBanner` 按事件大类 |
| 落点弹窗 / 格子详情 | `SceneBanner` 按 `SpaceKind`（含赌场、交易所、探店） |
| 公园小坐 | 行首 sm 肖像 |
| 约会选人 | 两列 `card` 立绘卡，底部叠名字 + 阶段 + 进度 |
| 约会选场所 | 行首 16:9 场所缩略图；未解锁灰阶 + 「未解锁」 |
| 约会结果 | 场所图做底 + 搭档立绘升起 + 好感 +N 飘字（UI 本地 `TasteScene`，不入存档） |
| 结识遇见 | `xl` 全宽立绘 + 人设 blurb |
| 好友详情 | `xl` 立绘头图，底部叠名字 / 身份 / 阶段 |
| 好友列表 / 约会选人 | 好感 ≤ 0 时灰阶 + 「已疏远」角标 |
| 结算 | 按结局切换整屏底；「最难忘的关系」改为 `xl` 立绘 + 名字大字叠字 |

## 代码

- `web/src/ui/art.ts`：`SPACE_ART` / `VENUE_ART` / `CAREER_ART` / `EVENT_ART` / `HOME_ART` 等，`ALL_ART` 供测试
- `web/src/ui/components/SceneBanner.tsx`：`loading="lazy"`，加载失败自动隐藏
- `Portrait`：新增 `size="xl" | "card"`、`caption`、`estranged`
- `global.css`：`.screen-art` 整屏固定底图；`tokens.css`：`--banner-h*`、`--grad-fade`、`--grad-screen-fade`、`--grad-caption`、`--play-art-opacity`

- 不做背景动画
- 玩家 / AI 棋子头像仍不接
