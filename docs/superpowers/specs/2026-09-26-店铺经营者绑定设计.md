## 目标

玩家能**选择/更换**店铺经营者，经营区能**单店升级**。

## 规则

### 空地开店

- 动作：`LOCATION_BUY_VACANT { relationId }`  
- 人选：本人 `status !== 'broken'` 的关系  
- 现金不足 / 无人选 → 日志并关闭落点  
- AI：仍选好感最高者  

### 经营区菜单

1. **升级某店** — `LOCATION_UPGRADE_SHOP { shopId }`  
   - 花费 `0.2`；`level < 3` 则 level+1 且 `baseCashflow +0.08`；已满级则仅 `baseCashflow +0.03`  
2. **换经营者** — `LOCATION_REBIND_OPERATOR { shopId, relationId }`  
   - 免费；目标须未 broken；写日志  
3. 离开 — 现有 `LOCATION_SKIP`  

AI 经营区：有店且现金够 → 升级第一家可升的店（或第一家）；否则离开。

### 事件开店（offerShop）

本轮**保持**自动挂最高好感（避免事件选项后再插一步）。玩家可随后在经营区换绑。

## 不做

- 一店多人经营  
- 换绑收费  
- 店铺转让拍卖
