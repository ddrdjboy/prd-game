| 项 | 内容 |

| 日期 | 2026-09-26 |
| 状态 | 已定稿并落地 |

## 目标

降低后续 Cursor/Agent 改本仓库时的两类失败：

1. **需求漂移**：仍按 v1.0「掷骰走格」理解产品  
2. **架构越界**：把玩法数学写进 React、或在 UI 里旁路 `reduce`

## 已确认决策

| 项 | 选择 |
|---|---|
| harness 含义 | AI 开发上下文（非局内自动季、非评测脚本） |
| 主 PRD | 不整篇重写；升 v1.1，文首变更摘要 + 现行要点 + 子规格索引 |
| 深度 | 实用：`AGENTS.md` 含代码边界 + 文档阅读约定 |
| 载体 | **仅** 根目录 `AGENTS.md`，不建 `.cursor/rules/` |
| 细节真相 | 子规格 `docs/superpowers/specs/*`；冲突时以**代码 + 更新的子规格**为准 |

## 交付物

1. `AGENTS.md` — 唯一 AI 入口  
2. `docs/superpowers/specs/2026-09-25-45岁财富自由-PRD.md` — v1.1 摘要与索引  
3. 本文 — 设计记录

## 明确不做

- `.cursor/rules/**`  
- 重写主 PRD 全文  
- 评测 / CI agent 门禁  
- 把事件池、职业卡全文复制进 AGENTS

## 成功标准

- 新会话打开仓库后，AI 先读 `AGENTS.md`，知道拉霸推进、落点互动、文档索引与 `game/`/`ui/` 边界  
- 改约会 / 事务所 / 事件选择时，会跳到对应子规格而不是只读 v1.0 掷骰段落  
- 改规则走 `reduce` + 单测；不在 View 里写结算公式  

## 阅读顺序（写入 AGENTS）

1. `AGENTS.md`  
2. 主 PRD 文首「变更摘要 / 现行要点 / 子规格索引」  
3. 任务相关子规格  
4. `web/src/game/` 对应模块 + `web/tests/`
