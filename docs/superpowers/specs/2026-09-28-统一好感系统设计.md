## 目标

取消 `network` / `romance` 与订婚结婚。所有关系共用一条好感轴；阶段解锁互动场景，并分流关系类事件选项。终局为 **财富 + 关系** 两维。

## 六阶与刻度

`affinity ∈ [-100, 500]`（整数）。阶段由分数推导，不双写。

| 阶段 | id | 区间 | UI |
|------|-----|------|-----|
| 仇恨 | hate | **-100 … 0** | 显示负数；条 -100→0（**反向**：越负越恨） |
| 冷淡 | cold | 0 &lt; a ≤ 100 | 进度 = a |
| 中立 | neutral | 100 &lt; a ≤ 200 | 进度 = a−100 |
| 友善 | friendly | 200 &lt; a ≤ 300 | 进度 = a−200 |
| 亲近 | close | 300 &lt; a ≤ 400 | 进度 = a−300 |
| 亲密 | intimate | 400 &lt; a ≤ 500 | 进度 = a−400（满 100） |

- `a <= 0` → 仇恨（含 0）；再 `+1` 进冷淡  
- 初识 RNG：冷淡 40 / 中立 150 / 友善 240，权重 3:5:2（不进仇恨/亲密）

## 加减好感：`applyAffinityDelta`

中心 `CENTER = 150`（中立中点）。同向远离中心乘阶段系数；朝中心 ×1.1。阶段内越靠外端同向越钝（×`1−0.45·p/100`）。仇恨段用深度 `−affinity` 做负向钝化；和解不加阶段钝化。跨边界拆步；硬夹 `[-100,500]`。

所有互动 / 事件 / 衰减 / 事务所调分必须走此函数。

## 互动场景

入口文案「互动」。选人 → 选场景 → 扣 AP/钱。

| id | 名称 | 最低阶段 | 花费 | 原始好感 |
|----|------|----------|------|----------|
| chat | 简单聊聊 | 仇恨 | 0 | +4 |
| park | 公园散步 | 中立 | 0.05 | +6 |
| cafe | 咖啡厅 | 友善 | 0.12 | +9 |
| cinema | 电影院 | 友善 | 0.20 | +12 |
| dinner | 餐厅正餐 | 亲近 | 0.35 | +16 |
| hobby | 共同爱好 | 亲近 | 0.28 | +18 |
| surprise | 惊喜安排 | 亲密 | 0.55 | +22 |
| private | 专属小旅行 | 亲密 | 0.80 | +28 |

未解锁灰显。特质 `relationBoost`：互动原始好感 +4。

## 事件

关系类牌绑定目标关系后按阶段取 `choiceSets`（或 `minStage`/`maxStage` 过滤）。效果：

- `{ type: 'meet', affinity?: number }`
- `{ type: 'boostRelation', amount, relationId? }`（默认上下文目标或随机）

## 衰减 / 锁定

未维护每回合 −4（`locked` −1），走 `applyAffinityDelta`。友善及以上且本回合维护过可 `locked`。无 `broken` 状态。

## 结算 / 财务

- `relationScore`：Σ `max(0,affinity)` ×（亲近 1.15 / 亲密 1.3），仇恨不贡献  
- 删除 network/romance 分与婚姻开支  

## 存档迁移

- 弃 `kind`/`status`；`score` → `affinity = clamp(round(score*5), 1, 500)`  
- 旧 `broken` → `affinity = -60`  

## 明确不做

棋盘格按好感上锁；完整兴趣送礼系统；多步约会剧情。
