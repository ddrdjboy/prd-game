# 私人事务所设计规格

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-25 |
| 状态 | 已定稿（实现基线） |
| 交互 | 落点三选一菜单（方案 1） |

## 目标

落点「私人事务所」提供三项关系操作：

1. **推荐好友** — 花钱给自己结识新人（人脉/恋人）
2. **调好感** — 对自己或他人关系升温/降温
3. **挖角抢人** — 手动选对手与目标关系，花钱判定夺取

与「好友」只读浏览、「约会·交友」行动点升温区分：事务所是 **落点对抗/中介**。

## 总流程

```
踏入事务所 → 菜单（推荐 / 调好感 / 挖角 / 离开）
  → 子流程选参 → 扣费结算 → 关闭落点
```

任一项结算成功或「离开」后清除 `pendingLocation`。现金不足选项禁用。

## 1. 推荐好友

- 选类型：`network` | `romance`
- 花费：`0.25` 万
- 效果：新增关系，初始好感 `35 + floor(rng*11)`（35～45），状态人脉 `new` / 恋人 `dating`
- 名册：沿用现有 `NETWORK_NAMES` / `ROMANCE_NAMES`

## 2. 调好感

- 范围：
  - 自己的全部非 broken 关系
  - 其他玩家的非 broken 且未 locked 关系
- **升温**：花费 `0.15`；自己目标 `+10`，他人目标 `+6`
- **降温**：花费 `0.2`；自己目标 `-12`，他人目标 `-10`；分 ≤10 且降温 → `broken`
- 写日志标明操作者与目标归属

## 3. 挖角抢人

- 步骤：选手家（非自己）→ 选其 `!locked && status !== broken` 关系
- 花费：`0.35` 万（确认时扣，失败也扣）
- 成功率：好感 >70 → 15%，否则 35%
- 人类受害者：`pendingDecision.poach`（挽留/放人），沿用现逻辑；发起方已扣费
- 成功：`transferRelation`（好感 -20 下限 20，解锁；原主该人经营店铺移除）
- 失败：仅日志

## 数据 / 动作

- `pendingLocation` 保留；子状态可用 UI 本地步骤或 `pendingOffice: { step, ... }`
- 建议动作：
  - `OFFICE_RECOMMEND { kind }`
  - `OFFICE_ADJUST { ownerId, relationId, direction: 'up' | 'down' }`
  - `OFFICE_POACH { targetPlayerId, relationId }`
  - `LOCATION_SKIP` = 离开

## AI

有可挖目标且现金够 → 挖角；否则推荐人脉；否则离开。

## 明确不做

- 同一落点连续办多项
- 锁定关系可调/可挖
- 拍卖竞价、完整情报偷看
