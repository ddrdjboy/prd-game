# 关系季衰减设计

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-26 |
| 状态 | 实现基线 |
| 动机 | 疏于维护无压力，约会可永久跳过 |

## 目标

每名玩家**结束自己的回合**时，对其未破裂关系降温；过低则破裂，迫使约会/事务所升温有意义。

## 规则

| 条件 | 每回合衰减 |
|---|---|
| `status !== 'broken'` 且 **未** `locked` | −4 |
| `locked`（结婚 / 事业合伙人等） | −1 |
| 衰减后 `score ≤ 10` | → `broken`，`locked = false`；经营该人的店铺保留但 CF=0（现有逻辑） |

- 触发点：`END_TURN` 成功结算前，对**当前回合玩家**结算一次  
- 本回合刚约会加分后再衰减：净效果仍可为正（约会仍值得做）  
- 写日志：有人降温时一句摘要；有人破裂时点名  

## 配置（`config.ts`）

- `RELATION_DECAY_UNLOCKED = 4`  
- `RELATION_DECAY_LOCKED = 1`  
- `RELATION_BREAK_AT = 10`  

## 不做

- 按季节全局一次衰减（改为每人每回合，与 AP 节奏对齐）  
- 衰减时自动降级 status（partner→stable 等）——保持简单  
- 强制约会打断
