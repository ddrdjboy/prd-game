# 赌场小游戏设计（百家乐 / 骰子 / 21 点）

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-26 |
| 状态 | 已实现 |
| 取代 | 落点赌场一键 `LOCATION_GAMBLE`（约 45% 翻倍） |
| 保真 | 规则与赔率尽量贴近真实赌场（玩家长期略亏） |

## 目标

- 赌场落点进入**会话**：可换桌、连玩，点「离开赌场」才关闭落点
- 三桌：**百家乐**、**骰子（Craps 精简）**、**21 点**
- 交互有发牌/掷骰与可选动作（非一键抽奖）

## 会话模型

```ts
pendingCasino: null | {
  playerId: string
  screen: 'lobby' | 'baccarat' | 'dice' | 'blackjack'
  // 各桌局内状态（见下）；大厅时 table 为空
  table: null | BaccaratState | DiceState | BlackjackState
}
```

- 踩 `casino` 格 → 设 `pendingCasino = { screen: 'lobby', table: null }`（可保留 `pendingLocation` 至离开，或离开时一并清）
- **大厅**：三桌入口 +「离开赌场」→ `pendingCasino = null` 且 `clearLocation`
- 桌内「返回大厅」：结束当前未结算局（若已扣注需先结算或禁止中途逃注——**已扣注必须打完本局**）
- 注码档：`0.2 / 0.5 / 1.0` 万（与现 `CASINO_BETS` 对齐）；现金不足不可开局

### 动作（建议）

| Action | 含义 |
|--------|------|
| `CASINO_LEAVE` | 离开赌场 |
| `CASINO_LOBBY` | 回大厅（仅 `table` 可空或已结算） |
| `CASINO_OPEN { game }` | 进某桌，选注前 |
| `CASINO_BET { amount }` / 各桌专用 bet | 下注入局 |
| 各桌专用：`BACARAT_PICK`、`DICE_*`、`BJ_HIT` / `STAND` / `DOUBLE` / `SPLIT` / `INSURANCE` / … | 局内操作 |

具体命名实现时可收拢为 `CASINO_ACT { kind, payload }`，规格以语义为准。

### AI

- 进场：最多 1～2 局（steady 0～1，aggressive 2，social 1）后 `CASINO_LEAVE`
- 优先选注最小档；21 点用简单策略（≤11 要牌、硬 17+ 停等）

## 百家乐

### 规则

- 标准点值：A=1，2–9 面值，10/J/Q/K=0；手牌点数 = 点数之和 mod 10
- 闲、庄各先 2 张；按**标准补牌表（tableau）**决定是否第三张
- 玩家开局前押一侧（可只押一注本轮）：**闲 / 庄 / 和**

### 赔率

| 押注 | 赢 | 备注 |
|------|-----|------|
| 闲 | 1:1 | |
| 庄 | 0.95:1 | 5% 抽水（净得 0.95×注） |
| 和 | 8:1 | 和局时庄/闲注**退还** |

### UI 流程

选注种 + 金额 → 发牌动画/展示 → 结算 → 可再来一局或回大厅

## 骰子（Craps 精简）

本轮不做全桌 odds/place/hardways；只做：

### Pass Line

1. Come-out：7/11 → 赢 1:1；2/3/12 → 输；其余立 **point**
2. Point 阶段：掷出 point → 赢 1:1；掷出 7 → 输；其它继续掷

### Don't Pass

- Come-out：2/3 赢 1:1；7/11 输；**12 推注**；其余立 point
- Point：7 赢；point 输；其它继续

### Field（一次性，与 line 独立可选或本轮仅作单独小玩法）

- 一掷：3/4/9/10/11 → 1:1；2 或 12 → 2:1；5/6/7/8 → 输

**建议 UI**：桌面主玩 Pass / Don't Pass（二选一）；Field 作为附加可选注（同时下则 come-out 一掷同时结算 Field）。

### 展示

双骰点数 + 当前 point（若有）+ 可「再掷」按钮（point 阶段）

## 21 点

### 牌靴与庄家

- **6 副牌**鞋；用尽或低于阈值时洗牌（实现可用数组鞋 + rng）
- 庄家：**硬/软 17 均停**（S17，写死）
- 庄家有 A 时提供**保险**

### 玩家动作

| 动作 | 条件 |
|------|------|
| 要牌 Hit | 未爆、未停 |
| 停牌 Stand | |
| 加倍 Double | 仅前两张（分牌后各手同样规则） |
| 分牌 Split | 前两张同点（十类互认）；本轮 **只分一次** |
| 保险 Insurance | 庄明牌为 A；金额为注的一半 |

### 赔率

| 结果 | 赔付 |
|------|------|
| 玩家 BJ 且庄非 BJ | **3:2** |
| 普通赢 | 1:1 |
| 保险猜中庄 BJ | 2:1（保险注） |
| 双方 BJ / 同点 | 推注 |
| 爆牌 / 输 | 失去该手注 |

### UI 流程

下注 → 发两张（庄一张暗牌）→ 保险（若有）→ 玩家逐手操作 → 庄开牌按规则要牌 → 结算 → 再来或回大厅
