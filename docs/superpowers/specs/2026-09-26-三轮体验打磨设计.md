# 三轮体验打磨设计（弹层 / 连爆 / 进度爽感）

| 项 | 内容 |
|---|---|
| 日期 | 2026-09-26 |
| 状态 | 已实现（单测 + e2e 通过） |
| 原则 | 不扩系统；修卡顿感、强化核心幻想、让进度可读 |

## 第 1 轮 — 弹层队列 + 空地空态

**问题：** `pendingDecision` 与 `pendingLocation` 可同时挂载，双 modal 叠层；空地无人脉时 CTA 含糊。

**做法：**
1. `resolveEventChoice`：凡 `applyEffects` 后留下 `pendingDecision`，一律把落点写入 `deferredLocation`（对齐晋级逻辑），不立刻 `pendingLocation`。
2. PlayScreen：有 `pendingDecision` 时不渲染落点弹层（双保险）。
3. 空地 0 关系：文案「暂无人脉可托管，可雇临时店员，或先去事件/事务所结识」。

**验收：** 决策关闭后才出落点；空地无关系有明确 CTA；单测覆盖 defer。

## 第 2 轮 — 777 连爆 settle

**问题：** 组合奖只在日志/`slotHint`，停轮无专属节拍。

**做法：**
1. `config.COMBO_HOLD_MS = 420`（`?fast=1` 时 0）。
2. SlotMachine：停轮后若有 `comboLabel`，加 `combo-win` / `combo-777` 类 + 角标展示标签。
3. PlayScreen：有 combo 时延后 `FINISH_MOVE` 节奏（hold 后再走棋），现金仍只发一次。

**验收：** 777/对子/带7 可见区分；fast 不拖；单测/逻辑不重复发奖。

## 第 3 轮 — 人生进度 + 发薪/晋级可读

**问题：** TopBar 只显财富自由%，年龄像「卡住」；晋级启动金只在日志。

**做法：**
1. TopBar：双轨——「人生」`(age-START)/(END-START)` +「自由」原 progress；标签写清。
2. 晋级弹层：展示 `INVESTOR_START_BONUS` 与被动>支出提示。
3. 轻量 `momentBanner`：发薪（含年轻红利）、晋级确认后闪 1.2s（读最新 log 或 action 回传）。

**验收：** 一眼分清岁数进度 vs 自由%；晋级前看到 +0.8；发薪有短横幅。

## 不做

新事件池、改自由路径概率、粒子引擎、结算分享图。
