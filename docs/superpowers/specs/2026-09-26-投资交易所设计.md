## 目标

- 踩 `invest` 进入**交易所会话**（对齐赌场）
- **理财柜**：保留债基 / ETF 等目录买卖，可回大厅
- **交易盘**：多棒迷你局（股票现货 + 币圈杠杆），本落点只开一局，收盘/爆仓/离开后回大厅

## 会话

```ts
pendingExchange: null | {
  playerId: string
  screen: 'lobby' | 'funds' | 'trade'
  tradeSessionsPlayed: number // 上限 1
  trade: null | TradeSession
}
```

- 踩 invest → `exchangeEnter`（lobby）
- `EXCHANGE_LEAVE` / `LOCATION_SKIP` → 清 pendingExchange + pendingLocation
- 交易盘开局扣入场金进局内 `cash`；离场市价平仓后并回玩家现金
- **不**写入 `PlayerState.investments`

入场金：`0.5 / 1.0 / 2.0` 万；每局最多 8 棒。

## 爆仓

统一维持保证金率 20%：杠杆仓权益 / 名义 < 0.2 → 强制平全部仓，剩余回现金，回大厅。

## AI

- 理财柜：沿用原 invest 策略后回大厅再离开
- 交易盘：小额入场、1～3 tick 后收盘；少用 5×

## 刻意不做

订单簿、融券做空、跨落点挂单、真实行情、交易盘进长期 investments。
