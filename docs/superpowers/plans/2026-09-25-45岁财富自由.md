# 《45岁财富自由》网页 MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 可在浏览器完整体验一局：职业 3 选 1 → 18–45 岁四季推进 → 双圈财报与关系开店 → AI 补位 → 自动季 → 45 岁结算。

**Architecture:** Vite + React + TypeScript。`src/game/` 纯逻辑（无 DOM），`src/ui/` 负责界面。局内状态单一 `GameState`，动作经 `reduce(state, action)` 推进；AI 与自动季调用同一套 reducer。

**Tech Stack:** Vite 5、React 18、TypeScript、Vitest、CSS Modules（无 UI 框架）

**Spec:** `docs/superpowers/specs/2026-09-25-45岁财富自由-PRD.md`

```ts
import { describe, it, expect } from 'vitest'
import { calcFinance, canPromote, isFinanciallyFree } from '../src/game/finance'
import type { PlayerState } from '../src/game/types'

function basePlayer(over: Partial<PlayerState> = {}): PlayerState {
  return {
    id: 'p0',
    name: '你',
    isHuman: true,
    careerId: 'dev',
    salary: 1.2,
    fixedExpense: 0.8,
    cash: 2,
    passiveIncome: 0,
    liabilities: 0,
    track: 'worker',
    position: 0,
    relations: [],
    shops: [],
    investments: [],
    actionPoints: 1,
    aiStyle: null,
    ...over,
  }
}

describe('finance', () => {
  it('sums passive from shops and investments', () => {
    const p = basePlayer({
      shops: [{ id: 's1', name: '小店', level: 1, baseCashflow: 0.3, operatorRelationId: 'r1' }],
      investments: [{ id: 'i1', name: '指数基金', cost: 1, cashflow: 0.1 }],
      relations: [{ id: 'r1', kind: 'network', name: '阿强', score: 80, status: 'stable', locked: false }],
    })
    const f = calcFinance(p)
    expect(f.passiveIncome).toBeGreaterThan(0.3)
    expect(f.totalExpense).toBe(0.8)
  })

  it('canPromote when passive > expense', () => {
    const p = basePlayer({ passiveIncome: 1, fixedExpense: 0.8, shops: [], investments: [] })
    // force via shops
    const rich = basePlayer({
      fixedExpense: 0.5,
      shops: [{ id: 's1', name: '店', level: 2, baseCashflow: 0.8, operatorRelationId: 'r1' }],
      relations: [{ id: 'r1', kind: 'network', name: 'X', score: 100, status: 'partner', locked: true }],
    })
    expect(canPromote(rich)).toBe(true)
    expect(canPromote(p)).toBe(false)
  })

  it('isFinanciallyFree same rule as promote threshold', () => {
    const rich = basePlayer({
      fixedExpense: 0.5,
      shops: [{ id: 's1', name: '店', level: 2, baseCashflow: 0.8, operatorRelationId: 'r1' }],
      relations: [{ id: 'r1', kind: 'network', name: 'X', score: 100, status: 'partner', locked: true }],
    })
    expect(isFinanciallyFree(rich)).toBe(true)
  })
})
```

- [ ] **Step 2: Run 确认失败**

- [ ] **Step 3: 实现 `finance.ts`**

- `relationMultiplier(score)`: `0.5 + score/200`（50→0.75, 100→1.0）
- 店铺现金流 = `baseCashflow * multiplier`（无经营者则 0）
- `totalExpense` = fixed + 关系维护（每人 `score>0 ? 0.02 : 0`）+ 婚姻额外 0.1 + 投资利息（负债 * 0.02）
- `netWorth` = cash + shopValues + investCosts - liabilities
- `canPromote` / `isFinanciallyFree`: `passiveIncome > totalExpense`
